# 生活小记 · 生活小知

一个公开的生活常识科普网站，包含日常物价参考、食材处理、洗衣护理、厨房技巧、家居清洁、收纳整理，以及生活解题局、超市天平、污渍侦探社、行李箱拼图四个互动小游戏。

使用原生 HTML、CSS、JavaScript 和原创 SVG 插画，无后端、无账号系统，不依赖 ChatGPT。

## 发布

GitHub Pages 从 main 分支的根目录发布。相对资源路径和 hash 路由兼容项目站点。

价格小抄为注明来源的参考资料，不是实时行情；更多日期与规格信息见页面来源说明。

## 视觉与字体

2026-11-18 更新为夏日泳池风格。`palette.css` 管理蓝白配色，`pool.css` 管理新版布局与圆体排版，`mobile-type.css` 管理手机阅读字号。全站采用用户选定的 A 版轻圆体：正文与导航使用寒蝉圆黑体 Normal，站名、标题与分类使用同家族 Regular；开源字体及插画说明见 [assets/summer/README.md](assets/summer/README.md)。无需运行构建命令即可预览和发布。

Tips 封面与步骤图使用蓝灰色描边和器物配色，食材与污渍保留辨识颜色。首页泳池叠加缓慢流动的光纹与扩散波纹，点击水面可出现涟漪；现有暂停按钮同时控制水面，离屏、切换窗口与减少动态效果偏好均可暂停或关闭动效。

首页以泳池纸条作为入口：小鹅携带纸条缓慢游动，点击或触屏轻点可展开真实手册中的第一步，拖动不会误触展开，方向键可移动。12 张精选纸条洗牌抽取，阅读时不自动切换，支持完整图解、返回、再捞一张及暂停。首页场景出现时隐藏页面散步鹅，离开后恢复。

页面导航使用主内容区的轻淡出与浮入（100ms + 220ms），顶栏保持稳定；快速连续选择会取消上一段过渡，以最后一次选择为准。返回图解前的页面会恢复原来的阅读位置。系统偏好减少动态效果、页面处于后台或浏览器不支持动画时直接切换。桌面端池边与标题保留独立间距，水面和光纹共用定位。

Hero 下方延续泳池主题：手册区使用低对比度水波和气泡，互动区加入泳池边条纹小旗与圆环，物价区使用细水波分隔，所有装饰均为 `pointer-events:none` 的背景层。

移动端首页默认展示 4 张 Tips 与 1 张生活纸条，卡片缩小以减少连续滚动；“浏览全部”会展开完整技巧列表，分类页不受此限制。
